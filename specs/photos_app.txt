Please write an MD specs file for Android application that should fetch a list of images from Flickr and display a staggered, grid of images on one screen and, a detail screen with one full screen image. This is link from where the images should be fetched:  https://api.flickr.com/services/feeds/photos_public.gne?format=json&nojsoncallback=1 . Home screen shows the grid of images, each item in the grid shows the image, image title and related tags. Image list allow to pull and refresh. User can also filter the images by selecting tags from bottom sheet. Bottom with tags can be open from the button in to app bar. Tags available in the bottom sheet are derived from image data fetched. There can be multiple tags selected and there should be a button to reset the filters. When user clicks the grid item new screen full screen for image detail opens. Image detail screen displays also the image title and related tags similar to grid items. There should be also number of fetched images displayed next to app title in the top app bar. When user filters the images the number updates accordingly. Filter button in top app bar should show number of applied filters. The app is optimized for landscape and portrait mode and for all screen sizes.
